This Python program generates random mazes and solves them using three search algorithms:

- Depth-First Search (DFS)
- Breadth First Search (BFS)
- A\* Search

Program Features:
- Random maze generation with adjustable blocked-cell proportion
- Visual output of maze paths
- Performance comparison between the above methods

This Maze solver demonstrates clean class design within an object-oriented framework, separating concerns between grid structure (Maze), data (Cell), and algorithm logic (DFS, BFS, A*).

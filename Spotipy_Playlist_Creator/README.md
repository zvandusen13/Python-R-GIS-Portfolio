This project creates new playlists in your Spotify library using the Spotipy library.
The program parses through your liked songs and creates playlists based on certain conditions
Those conditions being customizable are popularity, age of the artist, release year, and certain words in the lyrics

This program uses PySimpleGUI as the interface. Users will have to sign in to Spotify for the program to run on their account.
